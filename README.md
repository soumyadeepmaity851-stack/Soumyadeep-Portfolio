## 🌟 Key Highlights

- **Embedded Developer CLI Terminal**: In-browser command-line interface (`Ctrl + K` or backtick) with interactive commands (`skills`, `projects`, `education`, `contact`, `resume`, `sudo hire`).
- **Interactive AI/ML Inference Simulator**: Real-time convolutional neural network inference tester for automated visual defect detection with latency and layer analytics.
- **CampusDB Relational Engine**: C++ database query runner demonstrating B-Tree indexing and logarithmic $O(\log N)$ scan execution plans.
- **Interactive Skills Matrix**: Live code sandboxes for **C++**, **Python**, **Java**, **OOP Principles**, **DBMS**, **C**, **JavaScript**, and **HTML/CSS**.
- **Multi-Format Resume Engine**:
  - 1-Click Print & PDF generation (`@media print` clean ATS format).
  - Exportable in **Markdown (`.md`)**, **JSON Resume (`.json`)**, and **LaTeX (`.tex`)** formats.
- **Fluid Framer Motion Animations**: Smooth scroll-triggered fade & slide-in transitions with hardware-accelerated transforms.
- **Dual Theme Support**: Full dark and light theme switching with Tailwind CSS v4 variables.

- [Node.js](https://nodejs.org) (v18 or higher)
- [VS Code](https://code.visualstudio.com) (or any code editor)

```bash
# 1. Clone the repository
git clone https://github.com/soumyadeepmaity851-stack/portfolio.git

# 2. Navigate to the project directory
cd portfolio

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
